>用于编程 agent 的放行清单
>
>**可用于：**
>
>1. Claude code 
>2. Gemini CLI
>3. OpenCode
>4. Kiro
>
>**后续维护：**
>定期收集工作环境的放行清单，遇到新的命令申请则变更
